Professional Self-Assessment

Throughout my time at SNHU and in the Computer Science program, I’ve learned a lot and have grown as a developer. It is an interesting time to be pursuing a career in tech, and even more so in software engineering. AI has changed what the career looks like substantially, and many have questioned the value of learning computer science fundamentals, learning to code, and trying to get a job in this market. As someone nearing the end of my degree, I can say it was a pleasure learning and growing in this program, and I believe the fundamentals will always be important. I started this journey as someone who didn’t even know the difference between backend and frontend development. Now I’ve created full-stack applications, written complex algorithms to solve problems, deployed applications using a variety of methods, learned how to make applications secure, developed an understanding of how computers communicate, and so much more. This portfolio is the culmination of that journey and a demonstration of those skills.

Before I get into the project for this capstone, I want to reflect on some of the major projects that helped shape me into the developer I am now. In CS250, I was introduced to Agile development, Scrum roles, and how to handle changing requirements. This class helped me understand how to work in a flexible team environment. I learned how to adapt to changes and deliver a product that matches client expectations. This was a great connection between the technical side of my program and communicating with non-technical stakeholders. CYB210 helped me learn how networks work and how computers communicate with each other. I learned about IP addressing, subnetting, VLANs, and how to create and maintain a secure network. In CS300, I worked on projects that implemented data structures and algorithms by hand. I learned about Big O notation and how to compare the time and space complexity of different data structures and algorithms. It gave me a better understanding of when to use a particular solution and how to choose the best fit for a problem. I learned about client/server development in CS340 when I worked with MongoDB and Python to create an interactive dashboard connected to a database that queried map and location data. It helped me understand how databases store data and how to retrieve that information and use it in an application. CYB200 gave me insight into making secure applications and considering vulnerabilities that might exist within my software. I developed a security mindset and have carried that forward in my development process.

CS465 and CS470 helped put everything together through creating two full-stack applications. I built frontend interfaces and APIs, connected to databases, implemented authentication and CRUD functionality, and learned about serverless architecture for hosting applications in the cloud with AWS. Outside of my coursework, I’ve also applied what I’ve learned in my current full-time job. I work as a Civil 3D CAD Technician, and I’ve used Python, C#, and the .NET framework to develop tools and Dynamo scripts that automate some of the more tedious tasks I do at work, such as dimensioning parcel angles for plats. One script I created using a mix of Python and Dynamo’s visual programming reduced my time spent dimensioning angle points by about 60–75%. This has been a great opportunity to take my skills and create real-world value from them.

These experiences have helped shape my goal of pursuing software engineering, especially work where I can solve practical problems and improve existing processes. I value software that is useful, maintainable, and secure. Applying what I’ve learned at work has also shown me that I enjoy finding opportunities for automation and turning them into tools that save people time.

All of these courses and experiences, from my first introduction to Python to deploying full-stack applications in the cloud, have brought me to this capstone and given me the skills to complete it. The technical work in this portfolio centers on the Weight Tracker Android application I originally developed in CS360 using Java and SQLite. For my capstone, I enhanced the same application in three areas: software engineering and design, algorithms and data structures, and databases.

The enhancements build on one another. First, I separated the application’s responsibilities into model, service, and database layers, making the code easier to maintain and extend. I then added analytics that turn weight records into useful information, including averages, trends, logging streaks, and goal estimates. Finally, I improved database operations and password security while preserving existing user accounts and records. Together, these enhancements demonstrate my ability to evaluate existing software and improve its structure, functionality, efficiency, and security. The code review and accompanying narratives explain my decisions and the challenges I worked through, while the code shows how I put those decisions into practice.
